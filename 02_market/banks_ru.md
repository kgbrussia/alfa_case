# Конкурентный анализ: банки РФ для начинающих предпринимателей

Роль: конкурентный аналитик. Дата: июль 2026. Оценки «для нашего сегмента» — относительно персон из `/01_research/persona.md` и отраслей из решения №2 (розница/МП, бьюти, HoReCa).
Важно: тарифы меняются (с 01.01.2026 на комиссии эквайринга начисляется НДС 22%, что подняло ставки по всему рынку — [Т-Банк, тарифы](https://www.tbank.ru/business/payments/acquiring/tariffs/)). Все ставки — ориентиры на дату сбора, перед презентацией перепроверить.

---

## 1. Т-Банк (Т-Бизнес)

**Старт-продукты:** бесплатная онлайн-регистрация ИП; РКО с бесплатным стартовым тарифом; торговый эквайринг **от 1,2%** (без НДС) + терминал за 0 ₽; СБП **от 0,2%**; интернет-эквайринг без абонплаты, ставка под оборот/отрасль; онлайн-бухгалтерия для ИП на УСН/патенте встроена ([тарифы](https://www.tbank.ru/business/payments/acquiring/tariffs/), [обзор 1000bankov](https://1000bankov.ru/rko/ekv/tbank/)).
**Для молодых/начинающих:** медиа «Бизнес-секреты» (сильнейший контент-маркетинг для новичков), гайды «ИП несовершеннолетнему»; специальной молодежной бизнес-программы нет — есть Т-Банк Джуниор, но это детский/подростковый B2C, не бизнес.
**AI:** «Вселенная AI-ассистентов» (с 2024), в 2025–2026 — переход к специализированным агентам под сценарии экосистемы; ассистент Тая (2026). Бизнес-специфичного AI-консультанта для микробизнеса в открытых источниках не зафиксировано [ТРЕБУЕТ ПРОВЕРКИ] ([ai.tbank.ru](https://ai.tbank.ru/), [обзор стратегии](https://spektr.team/tpost/07kl5gtc21-ai-strategiya-t-banka-tehnologicheskii-s)).
**Онбординг:** заявка онлайн → выезд представителя с документами (1–2 дня) → счет; эквайринг — терминал с доставкой, обычно 1–3 дня [ТРЕБУЕТ ПРОВЕРКИ точных SLA].
**Сильное для сегмента 17–25:** бренд №1 по доверию у зумеров (pains.md §1), лучший обучающий контент, все онлайн.
**Слабое:** нет продуктовой «лестницы» для самозанятых → ИП; AI-активность направлена на B2C, не на спасение микробизнеса.

## 2. СберБизнес

**Старт-продукты:** бесплатная регистрация ИП; линейка РКО с нулевым базовым тарифом; торговый эквайринг **от ~1,3%**, ставки индивидуальны от оборота; интернет-эквайринг через ЮKassa (**до 2,5%**, подключение от 1 дня); кассы через СберБизнес; бухгалтерия встроена ([Сбер, справка](https://www.sberbank.ru/help/business/acquiring/2950), [Рег.ру обзор](https://www.reg.ru/web-tools/torgovyj-ekvajring)).
**Для молодых/начинающих:** образовательная платформа СберБизнес Live, курс «Свое дело» для самозанятых; отдельного трека 17–25 нет.
**AI:** **GigaChat интегрирован в СберБизнес** — генерация карточек товаров для селлеров, аналитика продаж в едином окне ([обзор](https://1000bankov.ru/rko/tarify/sberbank/)); самая широкая AI-инфраструктура на рынке РФ.
**Онбординг:** онлайн-заявка, счет от 1 дня; для эквайринга — договор + оборудование, по рынку 2–5 дней [ТРЕБУЕТ ПРОВЕРКИ].
**Сильное:** максимальный охват, ЮKassa — стандарт интернет-платежей, GigaChat уже в продукте.
**Слабое:** воспринимается зумерами как «банк родителей» (зумеры доверяют цифровым банкам — pains.md §1); интерфейсы и тарифная сетка сложны для новичка; AI-функции точечные (контент), не сопровождающие.

## 3. Точка

**Старт-продукты:** тариф «Ноль» без абонплаты для начинающих; торговый эквайринг **от 1,14% с НДС** (льготные отрасли), стандартные — от ~2,8%; СБП **0,4–0,7%**; мобильный эквайринг 2,7%; интернет-эквайринг от 2,8%; регистрация ИП бесплатно; сильная встроенная онлайн-бухгалтерия ([tochka.com/acquiring](https://tochka.com/acquiring/sale/), [тарифы ИП](https://tochka.com/tariffs/ip/)).
**Для молодых/начинающих:** глубокая специализация на селлерах МП (аналитика, «Точка Маркетплейсы»); исследования аудитории зумеров (совместно с Яндекс Маркетом); онбординг-контент «Справочная».
**AI:** **ИИ-Ассистент селлера (январь 2026) для 500 000+ продавцов Wildberries**; заявленный вектор 2026 — персональный финансовый и стратегический консультант 24/7, автоматическое выявление проблемных зон бизнеса ([CNews](https://www.cnews.ru/news/line/2026-01-23_tochka_bank_zapustil_ii-assistenta)). **Это самый близкий конкурент нашей будущей концепции AI-сопровождения.**
**Онбординг:** полностью онлайн, счет открывается быстро (день), культ UX.
**Сильное:** лучший продукт для Селлера; единственный банк, публично строящий AI-консультанта от проблемных зон бизнеса.
**Слабое:** нет собственной большой розничной базы физлиц (нельзя «растить с 14 лет»); слабее в офлайн-отраслях (бьюти, HoReCa) — фокус на онлайн-торговле; нет своих дочерних сервисов уровня «Подели»/«Нетмонет».

## 4. Модульбанк

**Старт-продукты:** банк, исторически сфокусированный на микробизнесе и селлерах; спецтарифы для селлеров ([modulbank.ru](https://modulbank.ru/marketplace/tarify-dlya-sellerov/)); эквайринг, кассы (Модулькасса — собственное кассовое решение), бухгалтерия [детальные ставки 2026 — ТРЕБУЕТ ПРОВЕРКИ].
**Для молодых:** специальных программ 17–25 не выявлено; позиционирование «банк для малого бизнеса» без возрастного акцента.
**AI:** публично значимых AI-продуктов для клиентов не зафиксировано [ТРЕБУЕТ ПРОВЕРКИ].
**Онбординг:** онлайн, быстрый (сопоставим с Точкой).
**Сильное:** Модулькасса — интегрированное кассовое решение; понимание микробизнеса.
**Слабое:** маленький бренд для зумера (нет в топе доверия), ограниченные ресурсы на AI и экосистему.

## 5. ВТБ

**Старт-продукты:** бесплатная онлайн-регистрация ИП (паспорт+ИНН+СНИЛС); РКО с бесплатным базовым тарифом; **июль 2026 — спецтарифы для селлеров WB/Ozon/ЯМаркет** в двух пакетах («старт» и «активные продажи») с бесплатной аналитикой спроса, конкурентов, автоценами ([Ведомости](https://www.vedomosti.ru/finance/news/2026/07/10/1212497-sistemu-skidok), [ДП](https://www.dp.ru/a/2026/07/10/vtb-objavil-o-zapuske-spectarifov), [vtb.ru](https://www.vtb.ru/malyj-biznes/)).
**Для молодых:** отдельных программ 17–25 не выявлено.
**AI:** клиентских AI-продуктов для малого бизнеса в открытых источниках не зафиксировано [ТРЕБУЕТ ПРОВЕРКИ].
**Онбординг:** онлайн-регистрация ИП + счет; скорость средняя по рынку.
**Сильное:** госмасштаб, свежий фокус на селлеров (подтверждает наш выбор отрасли), правовая поддержка 24/7.
**Слабое:** имидж «взрослого» банка, нет эмоциональной связи с сегментом, AI отстает.

## 6. Озон Банк

**Старт-продукты:** бесплатное открытие и обслуживание счета от 0 ₽ ([finance.ozon.ru/business](https://finance.ozon.ru/business)); кредиты под обороты на Ozon; мгновенный доступ к выручке селлера внутри платформы.
**Для молодых:** программ нет, но порог входа на Ozon сам по себе втягивает молодых (90% зумеров стартуют на МП).
**AI:** AI-инструменты Ozon для продавцов (карточки, реклама) — на стороне маркетплейса, не банка.
**Онбординг:** для селлера Ozon — фактически нулевой (счет в один клик из кабинета продавца). **Это эталон скорости входа, который банкам вне платформы не повторить.**
**Сильное:** инфраструктурная монополия на своих селлеров: видит продажи до банка, платит быстрее, кредитует под обороты платформы.
**Слабое:** клиент заперт в одной платформе; вне Ozon (бьюти, HoReCa, свой канал) банк бесполезен; РКО-функциональность беднее классических банков.

## 7. Дополнительный игрок: ЮMoney/ЮKassa (экосистема Сбера)

Стандарт де-факто интернет-эквайринга для микробизнеса и самозанятых (платежные ссылки, виджеты, до 2,5%+); часто первый «платежный» продукт до всякого банка. Учитывать как канал, через который Сбер перехватывает онлайн-новичков.

## 5 выводов: дыры, которые может занять Альфа

1. **Ни у одного банка нет трека «17–25» и тем более «14–17».** Все работают с «начинающими» без возраста; юридическую специфику несовершеннолетних (НПД с 14, эмансипация) не упаковал никто. Дыра целиком свободна — и у Альфы есть розничная молодежная база (Alfa Only, детские карты) для конвертации [ТРЕБУЕТ ПРОВЕРКИ размеров базы — запрос в банк].
2. **AI-сопровождение бизнеса только зарождается, и только у Точки** — причем для селлеров WB. Никто не делает AI-«предупредителя смерти бизнеса» на транзакционных данных для офлайн-отраслей (бьюти, HoReCa). Окно возможности: 12–18 месяцев, пока Точка не масштабировалась за пределы МП.
3. **Все конкурируют на этапе «у клиента уже есть бизнес», никто — на этапе «хочу, но боюсь»** (этап 1–2 CJM, где отваливается больше всего — 60% хотят / 4% ведут). Контент есть (Бизнес-секреты, СберБизнес Live), продукта-навигатора «доведи меня от идеи до первого платежа» нет ни у кого.
4. **Селлерский сегмент перегрет** (Точка, Модуль, ВТБ с июля 2026, Озон Банк с инфраструктурным преимуществом) — лобовая атака тарифами бесперспективна. Зато **бьюти и молодой HoReCa банками недообслужены**: там правят небанковские YCLIENTS/Dikidi/iiko без банковской лицензии и данных. У Альфы уникальные активы под эти отрасли: «Нетмонет» (чаевые+QR-счета) и «Подели».
5. **Онбординг-эталон задан Озоном (счет в 1 клик из кабинета), а не банками.** Классический путь «заявка → выезд представителя → терминал через N дней» для зумера архаичен. Цель Альфы: «первый принятый платеж в день обращения» через СБП/AlfaPOS без железа — технически возможно уже сейчас, вопрос упаковки.

**Честная оговорка про Альфу:** у Альфы уже есть «Нейроофис» — AI-сервис для бизнеса ([пресс-релиз](https://alfabank.ru/news/t/release/alfa-bank-zapustil-novii-servis-dlya-biznesa-na-baze-iskusstvennogo-intellekta--neiroofis/), [страница](https://alfabank.ru/sme/abp/services/neuro_office/)) — стратегия должна строиться на нем, а не игнорировать его (передано стратегу и AI-архитектору) [ТРЕБУЕТ ПРОВЕРКИ функционала Нейроофиса — сайт недоступен из среды].
