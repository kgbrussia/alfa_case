# Экосистема инструментов молодого предпринимателя: карта «зоопарка»

Роль: аналитик экосистемы инструментов. Вход: `/01_research/cjm.md`, `/01_research/pains.md`. Июль 2026.
Тезис кейса подтверждается инвентаризацией: путь новичка собирается из 8–15 несвязанных сервисов. Ниже — из чего состоит стек, что он закрывает и где предприниматель остается один.

**Чем AI уже хорош для сегмента:** контент (тексты/картинки/карточки) — закрыто почти бесплатно; ответы на типовые вопросы — закрыто (с риском галлюцинаций).
**Чем AI сегодня НЕ помогает:** он не знает реальных цифр бизнеса (обороты, маржа, остаток на счете), не несет ответственности за налоговые советы, не может ничего сделать (заплатить, отложить, оформить) — только поговорить.

## 3. Где предприниматель остается один (сквозные дыры стека)

1. **Интеграция:** запись (YCLIENTS) не знает о кассе, касса — о налогах, налоги — о остатке на счете. Единственный интегратор — сам предприниматель с таблицей.
2. **Деньги и налоги:** ни один популярный сервис не отвечает на вопросы «сколько я реально заработал?» и «хватит ли на налог и аренду?» — данные о деньгах есть только у банка.
3. **Страх ошибки перед государством:** сервисы констатируют (Эльба посчитает штраф), но не предотвращают; AI советует без гарантий. «Предохранителя» нет нигде.

## 4. Пять разрывов, где банк с платежными данными уникален

| # | Разрыв | Почему только банк |
|---|---|---|
| 1 | **«Правда о деньгах».** Сервисы видят записи/заказы/карточки — банк видит реальные поступления по эквайрингу/СБП/счету. Только банк может сказать «твоя реальная выручка упала на 18% к прошлому месяцу» | Данные транзакций — эксклюзив банка; внешним AI они недоступны в принципе |
| 2 | **Прогноз кассового разрыва.** Регулярные платежи (аренда, подписки, взносы) + входящий поток видны только в счете; прогноз «через 12 дней не хватит на аренду» не может построить никто, кроме банка | Полная картина притока/оттока |
| 3 | **Налоги в момент денег.** Автоматически откладывать 4–6% с каждого входящего платежа и формировать чек НПД может только тот, через кого идет платеж | Банк — точка прохождения денег; Mozen уже делает это для платформ — распространить на всех |
| 4 | **Комплаенс-предохранитель.** Предупредить «этот платеж вызовет вопросы по 115-ФЗ» до его проведения может только сам банк — сервисы узнают о блокировке вместе с клиентом | Банк — сторона контроля; превратить обязанность в сервис |
| 5 | **Отраслевые бенчмарки.** «Средний чек кофеен твоего района вырос, а твой нет» — построимо только на обезличенных данных эквайринга тысяч ТСП | Сетевой эффект данных эквайринга; у Альфы — один из крупнейших эквайринговых портфелей РФ [ТРЕБУЕТ ПРОВЕРКИ доли рынка] |

**Вывод для стратегии:** банк не должен воевать с YCLIENTS/МойСклад/Эльбой за их функции — он должен занять слой, который никто из них занять не может: деньги + прогноз + налоги + защита от государства + бенчмарки, и открыть интеграции остальным. «Зоопарк» побеждается не заменой всех животных, а единой нервной системой денег.
