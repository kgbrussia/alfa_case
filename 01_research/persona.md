# Персоны: поведенческие типы молодых предпринимателей 17–25

База: `/01_research/pains.md`. Персоны — не демографические портреты, а поведенческие типы, привязанные к трем главным сценариям входа сегмента в бизнес (маркетплейсы/онлайн-торговля, услуги/бьюти, офлайн-точка HoReCa). Покрывают приоритетные отрасли кейса: розница, бьюти, HoReCa.

Данные, на которых стоят типы: 43% несовершеннолетних предпринимателей — торговля, половина из них на маркетплейсах; 90% зумеров-клиентов Точки начали с маркетплейса; вход в бизнес чаще через самозанятость; пик регистрации ИП — 23 года (источники — pains.md §1).

---

## Персона 1. «Мастер без вывески» — услуги/бьюти без регистрации

| Параметр | Описание |
|---|---|
| **Контекст** | 18–20 лет, студент(ка) колледжа/вуза. Маникюр, ресницы, брови, стрижки — на дому или в коворкинг-кабинете почасово. Клиенты из соцсетей и сарафана, запись в Директ/Telegram. 20–60 клиентов в месяц. |
| **Деньги** | Доход 30–80 тыс. ₽/мес нерегулярно [ТРЕБУЕТ ПРОВЕРКИ — оценка по вилке доходов сегмента]. Стартовый капитал — 50–150 тыс. ₽ на обучение и материалы, из подработок и от родителей. Оплата — переводы на личную карту «как друг другу». |
| **Регистрационный статус** | Чаще никакого; продвинутые — самозанятость (НПД). Слово «ИП» пугает. Соответствует серой зоне из pains.md §1. |
| **Цифровые привычки** | Живет в Telegram и соцсетях; банк = мобильное приложение, отделение не посещала никогда. Запись клиентов — заметки/Google-таблица/YCLIENTS у продвинутых. |
| **Отношение к банкам** | Утилитарное: банк — это карта и переводы. Бизнес-продукты банка = «это для настоящих фирм, не для меня». Боится, что банк «заметит» поток переводов и заблокирует (боль №3 из pains.md §3, 115-ФЗ). |
| **Отношение к AI** | Ежедневный пользователь: тексты для постов, идеи контента, ответы клиентам (ChatGPT/Алиса — топ у молодежи, pains.md §6). AI — «подружка-советчица», не «технология». |
| **Ключевые страхи** | «Налоговая придет за переводы на карту»; «зарегистрируюсь — замучают отчетами»; «поднимут аренду кабинета — уйду в минус». |
| **Триггер обращения в банк** | (а) страх блокировки личной карты из-за потока переводов; (б) клиенты все чаще просят «оплату по QR как в салоне»; (в) решение снять свой кабинет — нужны «взрослые» инструменты. |
| **Продукты периметра** | Вход: самозанятость + прием по СБП (QR) + «Нетмонет» (чаевые). Рост: mPOS/AlfaPOS, «Подели» для дорогих процедур. |

## Персона 2. «Селлер» — розница/маркетплейсы

| Параметр | Описание |
|---|---|
| **Контекст** | 20–23 года. Продает на Wildberries/Ozon (одежда, аксессуары, товары из Азии). Начал с самозанятости и 30 тыс. ₽ закупки, теперь ИП на УСН. Работает из дома, 1–2 помощника на упаковке. Для 90% таких маркетплейс — первый бизнес-опыт (pains.md §1). |
| **Деньги** | Оборот скачет: 100 тыс. — 1 млн ₽/мес (средний оборот активного зумера-селлера — 394 тыс. ₽/мес, Точка+ЯМ). Маржа тонкая, вся прибыль реинвестируется в закупку. Кассовые разрывы — норма жизни: выплаты маркетплейса раз в неделю, закупка — сегодня. |
| **Регистрационный статус** | ИП на УСН «доходы» (вырос из НПД, уперся в лимит 2,4 млн). Регистрировал сам по YouTube-гайду, в налоговых режимах путается. |
| **Цифровые привычки** | Вся жизнь в личном кабинете маркетплейса, таблицах и Telegram-чатах селлеров. Аналитика — MPStats или подобные. Банк выбирал по скорости открытия счета. |
| **Отношение к банкам** | Прагматичное: счет — это труба между маркетплейсом и закупкой. Сравнивает тарифы поверхностно (боль №7 из pains.md §3). Лоялен нулю банков: переедет за день, если где-то быстрее/дешевле. Зумеры доверяют цифровым банкам (pains.md §1). |
| **Отношение к AI** | Активный рабочий инструмент: карточки товаров, SEO-описания, ответы на отзывы, реклама (58% зумеров-селлеров используют AI в рекламе — pains.md §6). Готов платить за AI, который считает юнит-экономику. |
| **Ключевые страхи** | «Маркетплейс поднимет комиссию или заблокирует карточку — бизнес умрет за неделю» (боль №8); «не хватит на закупку перед сезоном»; «налоговая насчитает больше, чем я отложил». |
| **Триггер обращения в банк** | (а) превысил лимит НПД — срочно нужен ИП и расчетный счет; (б) кассовый разрыв — ищет оборотку; (в) выход с маркетплейса в свой канал — нужен интернет-эквайринг. |
| **Продукты периметра** | Расчетный счет + интернет-эквайринг/«Твои платежи» (свой канал), массовые выплаты (помощники), «Подели» (конверсия в своем магазине), AlfaPay/СБП. |

## Персона 3. «Первая точка» — выпускник открывает HoReCa

| Параметр | Описание |
|---|---|
| **Контекст** | 23–25 лет, выпускник вуза, 1–2 года поработал в найме (часто в этой же сфере — бариста, администратор). Открывает кофейню/кофе-точку/фудтрак. Это «бизнес мечты», решение эмоциональное (71% мотивируются примерами успешных — pains.md §1). |
| **Деньги** | Стартовый бюджет 0,8–2 млн ₽: накопления + родители + иногда грант 14–25 лет (100–500 тыс. ₽, о котором узнал случайно). Кредит не берет — ставка пугает (барьер №2 по ВЦИОМ). Финмодели нет, есть таблица «примерно». |
| **Регистрационный статус** | ИП на УСН, зарегистрирован осознанно. Впервые сталкивается с полным комплектом: касса, 54-ФЗ, эквайринг, найм 2–4 человек, СЭС/пожарные. |
| **Цифровые привычки** | Компетентный пользователь: Notion/таблицы, iiko/r_keeper знает по найму. Читает Telegram-каналы про общепит и vc.ru. Банк — только приложение. |
| **Отношение к банкам** | Ожидает сервиса «как для людей»: быстро, понятно, без бумаг. Выбирает банк одним пакетом «счет+касса+эквайринг» — кто соберет проще, тот и выиграл (боль №7 из pains.md §2: «касса отдельно, счет отдельно — я запутался»). |
| **Отношение к AI** | Использует для меню, соцсетей, описаний вакансий; хотел бы AI-помощь в финплане и прогнозе выручки, но не знает инструментов. |
| **Ключевые страхи** | «Не выйду в ноль до конца денег» (HoReCa — в топе закрытий 2026, pains.md §3); «ошибусь с кассой — штраф»; «первый же кассовый разрыв убьет точку» (боль №5); «выгорю, делая все сам» (боль №6). |
| **Триггер обращения в банк** | Подписан договор аренды, дата открытия через 2–4 недели: срочно нужны счет, касса с 54-ФЗ, терминал, зарплатные выплаты. Это единственная персона, приходящая в банк сама — и сравнивающая 2–3 предложения. |
| **Продукты периметра** | Полный стек: торговый эквайринг + Альфа-Касса + СБП + AlfaPay, «Нетмонет» (чаевые команде), кассы самообслуживания (при росте), массовые выплаты (смены), «Подели» (кейтеринг/мерч — ограниченно). |

## Как использовать

- **Стратегу (Фаза 3):** три персоны = три ступени «лестницы взросления» клиента: Мастер (НПД, нулевая монетизация, максимальный LTV-потенциал) → Селлер (ИП, транзакционная монетизация) → Первая точка (полный стек Платежного бизнеса). Удержание = перевод клиента вверх по лестнице.
- **Продакту (Фаза 4):** у каждой персоны свой входной продукт: Мастер — СБП-QR/самозанятость; Селлер — счет+выплаты; Точка — пакет «открытие за неделю».
- **Маркетологу (Фаза 5):** Мастер и Селлер не приходят в банк сами — их надо ловить в соцсетях/чатах селлеров/бьюти-комьюнити; Первая точка приходит сама — ее надо не потерять на сравнении пакетов.
- 17-летние — не отдельная персона, а ранняя стадия Мастера/Селлера с юридическими ограничениями (pains.md §5): вход только через НПД с согласия родителей, кредитные механики — табу.
