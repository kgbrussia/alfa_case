# BRIEF: Стратегия Платежного бизнеса Альфа-Банка для молодых предпринимателей 17–25 лет

Рабочий бриф команды. Основан на кейсе чемпионата (см. `/README.md`). Все агенты сверяются с этим документом перед началом работы.

---

## 1. Цель

Разработать стратегию **привлечения и сопровождения** молодых предпринимателей 17–25 лет для Платежного бизнеса Альфа-Банка с осмысленным (не декоративным) применением AI. Результат: стратегия + продуктовые предложения + план продвижения + оценка эффекта для банка, упакованные в презентацию и MVP.

Ключевая рамка кейса:
- Молодые предприниматели формируют привычки и выбирают первых партнеров — банк, полезный на старте, растет вместе с клиентом.
- Главная причина оттока в сегменте — **не уход в другой банк, а закрытие бизнеса**. Поэтому сопровождение (доведение до устойчивого использования, помощь бизнесу выжить) равноценно привлечению.
- AI уже часть повседневности сегмента — он должен делать путь предпринимателя проще, а не быть «фичей ради фичи».

## 2. Сегмент

- **Фокус: 17–25 лет**, начинающие и будущие предприниматели (ИП, самозанятые, основатели микробизнеса).
- Допустим более широкий взгляд (например, 16–30) в исследовании и стратегии, но выводы и решение обязаны работать прежде всего для ядра 17–25.
- Особое внимание: 17-летние — несовершеннолетние (ограничения на регистрацию ИП, эмансипация, согласие родителей). Риски этого подсегмента фиксируются отдельно.
- Приоритетные отрасли для выбора фокуса (из кейса): **HoReCa, бьюти, розница, медицина, государственные учреждения, АЗС**. Команда выбирает 2–3 отрасли/сценария и обосновывает выбор данными.

## 3. Продуктовый периметр

Решение строится вокруг продуктов **Платежного бизнеса Альфа-Банка**:

| Группа | Продукты |
|---|---|
| Эквайринг | торговый эквайринг, интернет-эквайринг, легкий эквайринг mPOS |
| Кассы | Альфа-Касса, облачная касса, кассы самообслуживания |
| Приложения | AlfaCASH (касса в смартфоне), AlfaPOS (мобильный эквайринг) |
| Платежные методы | AlfaPay, прием оплаты по СБП |
| Выплаты | массовые выплаты |
| Дочерние сервисы | «Нетмонет» (чаевые), «Подели» (BNPL), Mozen (мгновенные выплаты), «Твои платежи» (онлайн-платежи и сплитование) |

Точные определения — в `GLOSSARY.md`. Можно адаптировать существующие продукты и предлагать новые, но связь с периметром Платежного бизнеса обязательна.

## 4. Критерии успеха решения (7 пунктов — что должно быть сделано)

- [ ] **КУ-1. Исследование ЦА**: мотивация, барьеры, боли, ожидания от банка, трудности запуска первого бизнеса — на реальных данных и цитатах, не на стереотипах.
- [ ] **КУ-2. Фокус**: выбраны 2–3 приоритетные отрасли/сценария из списка кейса, выбор обоснован цифрами.
- [ ] **КУ-3. Конкурентный анализ**: банки, финтех, AI-сервисы и небанковские инструменты для начинающих предпринимателей.
- [ ] **КУ-4. Инсайты и роль банка**: сформулированы ключевые инсайты и роль, которую Альфа-Банк занимает в жизни будущего предпринимателя.
- [ ] **КУ-5. Концепция стратегии**: ценностное предложение, ключевая идея, AI-компонент, ключевые продукты, механики удержания (включая работу с причиной оттока — закрытием бизнеса).
- [ ] **КУ-6. Продвижение**: реалистичная стратегия продвижения среди молодых предпринимателей.
- [ ] **КУ-7. Продукты и эффект**: предложены новые продукты/сервисы/доработки Платежного бизнеса, показана связь стратегии с его продуктами и эффект для банка.

## 5. Критерии оценки жюри — 5 групп (наша карта качества)

> Источник: реконструкция по постановке кейса и публичным описаниям кейс-чемпионатов «Альфа-Будущее» [ТРЕБУЕТ ПРОВЕРКИ по официальному положению чемпионата — при получении оригинала обновить, см. DECISIONS №1].

**Группа A. Глубина анализа**
- [ ] Исследование ЦА опирается на проверяемые источники (ссылки на каждую цифру).
- [ ] Конкурентная среда покрыта широко: банки + финтех + AI + небанковские сервисы.
- [ ] Данные свежие (2024–2026) и релевантные сегменту 17–25.

**Группа B. Инсайты и логика**
- [ ] Инсайты нетривиальны и следуют из данных, а не декларируются.
- [ ] Цепочка «боль → инсайт → решение → эффект» прослеживается без разрывов.
- [ ] Выбор отраслей и сегмента аргументирован.

**Группа C. Качество стратегии и AI-компонента**
- [ ] Ценностное предложение отличимо от конкурентов.
- [ ] AI решает конкретные боли сегмента, а не добавлен «для галочки»; понятно, почему AI, а не обычная автоматизация.
- [ ] Есть механики удержания и сопровождения (борьба с закрытием бизнеса), а не только привлечение.

**Группа D. Реализуемость и эффект**
- [ ] Решения совместимы с текущей инфраструктурой банка и периметром Платежного бизнеса.
- [ ] Есть оценка эффекта для банка (клиенты, обороты эквайринга, LTV/удержание) с прозрачными допущениями.
- [ ] Отсутствуют юридические и репутационные риски (особенно по несовершеннолетним и кредитным продуктам для 18−).

**Группа E. Подача**
- [ ] Структура презентации: понятна логика за 10 минут.
- [ ] Визуализация и MVP демонстрируют идею, а не заменяют ее.
- [ ] Ни одного выдуманного факта, названия продукта или цифры без источника.

## 6. Ограничения

1. **Совместимость с инфраструктурой банка**: решения строятся на реальных продуктах Платежного бизнеса и дочерних сервисах, без фантазийных платформ «с нуля».
2. **Юридические риски**: 54-ФЗ (кассовая дисциплина), 115-ФЗ (ПОД/ФТ), ограничения для несовершеннолетних (ГК РФ: дееспособность, эмансипация с 16 лет), режим НПД для самозанятых. Ни одно предложение не должно их нарушать.
3. **Репутационные риски**: никаких механик, которые можно прочитать как втягивание молодежи в долги (осторожно с BNPL для 18−), агрессивный маркетинг несовершеннолетним.
4. **Фактическая точность**: только реальные продукты, компании и данные; каждая цифра — источник или [ТРЕБУЕТ ПРОВЕРКИ].
