# GLOSSARY: термины кейса

Формулировки сверены с открытыми источниками (страницы alfabank.ru раздела «Эквайринг» проиндексированы поиском; прямой доступ к сайту из среды ограничен, поэтому часть определений подтверждена через кэш поиска и публикации банка — помечено источниками).

## Платежные термины

| Термин | Определение |
|---|---|
| **Эквайринг** | Услуга банка по приему безналичной оплаты (карты, смартфоны, QR) в пользу продавца. Банк-эквайер обрабатывает транзакцию и зачисляет деньги на расчетный счет продавца за вычетом комиссии. |
| **Торговый эквайринг** | Прием оплаты картами и смартфонами через POS-терминал в офлайн-точке (магазин, кафе, салон). |
| **Интернет-эквайринг** | Прием оплаты на сайте или в приложении: покупатель вводит данные карты (или платит через AlfaPay/СБП) на платежной странице. |
| **mPOS (легкий эквайринг)** | Прием оплаты через компактный терминал или смартфон с NFC вместо классического POS-терминала; подходит микробизнесу и выездным услугам с небольшим оборотом. |
| **СБП (Система быстрых платежей)** | Сервис Банка России и НСПК для мгновенных переводов и оплаты по QR-коду/платежной ссылке между банками. Для бизнеса комиссия при приеме оплаты по СБП ниже карточного эквайринга (тарифы СБП для ТСП регулируются Банком России). |
| **QR-эквайринг** | Прием оплаты по QR-коду (обычно через СБП): покупатель сканирует код и подтверждает платеж в своем банковском приложении, терминал не обязателен. |
| **54-ФЗ** | Федеральный закон «О применении контрольно-кассовой техники»: обязывает большинство продавцов выдавать фискальные чеки через онлайн-кассу с передачей данных в ФНС через ОФД. Самозанятые на НПД освобождены — чеки формирует приложение «Мой налог». |
| **НПД / самозанятость** | Налог на профессиональный доход — спецрежим (4% с доходов от физлиц, 6% от юрлиц, лимит 2,4 млн ₽/год) без обязательной онлайн-кассы; доступен с 14 лет с согласия родителей, с 16 лет по эмансипации [ТРЕБУЕТ ПРОВЕРКИ юристом]. |
| **BNPL (Buy Now, Pay Later)** | Оплата покупки по частям без оформления классического кредита: сервис платит продавцу сразу, покупатель гасит долю платежами по графику. |

## Продукты Платежного бизнеса Альфа-Банка

| Продукт | Что это |
|---|---|
| **Альфа-Касса** | Онлайн-касса Альфа-Банка «3 в 1»: кассовый аппарат с фискальным накопителем (передача чеков в ФНС по 54-ФЗ) и встроенным эквайрингом; линейка устройств MSPOS (покупка или аренда). Источник: alfabank.ru/sme/payservice/alfa-kassa/ |
| **Облачная касса** | Арендуемая онлайн-касса в дата-центре для интернет-торговли: фискализация чеков без физического устройства у продавца. |
| **AlfaCASH** | Мобильное приложение Альфа-Банка «касса в смартфоне»: прием наличных и безналичных платежей с фискализацией по 54-ФЗ без отдельного кассового аппарата. Источник: публикации банка о запуске AlfaCASH. |
| **AlfaPOS** | Мобильное приложение для эквайринга: прием оплаты картами и смартфонами через NFC-смартфон продавца без POS-терминала (tap-to-phone). Источник: alfabank.ru/sme/payservice/alfapos/ |
| **AlfaPay** | Платежный сервис Альфа-Банка (запущен в 2023): оплата в одно касание для клиентов банка — кнопка AlfaPay на сайтах без ввода реквизитов карты, оплата смартфоном (NFC, Mir Pay-инфраструктура) и по QR. Источник: alfabank.ru/sme/payservice/alfa-pay/ |
| **Кассы самообслуживания** | Терминалы, на которых покупатель сам сканирует и оплачивает товары (self-checkout) — сокращают очереди и затраты на кассиров. |
| **Массовые выплаты** | Сервис перечисления денег от компании множеству физлиц (исполнители, курьеры, самозанятые) по реестру или API. |

## Дочерние сервисы

| Сервис | Что это |
|---|---|
| **«Нетмонет» (нетмонет / «Нет монет»)** | Платформа цифровых чаевых и отзывов по QR-коду для сферы услуг; поддерживает оплату картой, через СБП и AlfaPay; также QR-оплата ресторанного счета. Источники: netmonet.co; пресс-релизы Альфа-Банка. |
| **«Подели»** | BNPL-сервис, партнер Альфа-Банка: оплата покупки 4 равными частями (25% сразу, остальное каждые 2 недели) без процентов для покупателя; лимит до ~35 тыс. ₽ [ТРЕБУЕТ ПРОВЕРКИ, лимит менялся]. Источники: podeli.ru; пресс-релизы Альфа-Банка. |
| **Mozen** | Сервис мгновенных выплат самозанятым и физлицам-исполнителям (таксопарки, курьерские и агентские схемы): моментальный вывод заработка на карту, автоматизация чеков НПД. Источник: mozen.io |
| **«Твои платежи» (Your Payments)** | Сервис приема и сплитования онлайн-платежей: прием оплаты и автоматическое разделение суммы между участниками сделки (маркетплейсы, платформы). Источник: ypmn.alfabank.ru |

## Прочее

| Термин | Определение |
|---|---|
| **ОФД** | Оператор фискальных данных — посредник, передающий чеки от онлайн-кассы в ФНС. |
| **ТСП** | Торгово-сервисное предприятие — продавец, принимающий безналичную оплату. |
| **Эмансипация** | Объявление несовершеннолетнего (с 16 лет) полностью дееспособным по решению органа опеки или суда (ст. 27 ГК РФ) — открывает путь к регистрации ИП до 18 лет. |
| **LTV / удержание** | Пожизненная ценность клиента; в кейсе критично: отток в сегменте вызван закрытием бизнеса, а не переходом в другой банк. |
