# PLAN: план работ по фазам

Каждая фаза закрывается только при выполнении Definition of Done (DoD). Артефакты — файлы в репозитории. Ответственный агент сверяет свой результат с чек-листом соответствующей группы критериев жюри (BRIEF, раздел 5).

## Структура репозитория

```
/00_project/      BRIEF.md, PLAN.md, STATUS.md, DECISIONS.md, GLOSSARY.md — управление проектом
/01_research/     исследование ЦА (pains.md и др.)
/02_market/       конкурентный анализ
/03_strategy/     инсайты, концепция, ценностное предложение, AI-компонент
/04_products/     продуктовые предложения и доработки
/05_gtm/          стратегия продвижения
/06_impact/       эффект для банка, экономика решения
/07_deliverables/ презентация, MVP, финальная сборка
```

## Фаза 0. Настройка проекта (руководитель) — DONE

**Артефакты:** структура папок, BRIEF.md, PLAN.md, STATUS.md, DECISIONS.md, GLOSSARY.md.
**DoD:** все пять документов в репозитории; критерии жюри оформлены чек-листами; решение №1 зафиксировано в DECISIONS.md; термины глоссария проверены по открытым источникам.

## Фаза 1. Исследование ЦА (UX-исследователь)

**Артефакт:** `/01_research/pains.md`.
**Содержание:** портрет сегмента 17–25 (численность, форма регистрации, ниши, источники стартового капитала); топ-10 болей «идея → запуск» и топ-10 болей «первые 6 месяцев»; отдельные блоки про деньги/платежи/кассы/54-ФЗ и про несовершеннолетних; использование AI сегментом; 5–7 выводов для стратегии.
**DoD:** ≥10 реальных источников со ссылками; каждая цифра с источником или [ТРЕБУЕТ ПРОВЕРКИ]; боли сформулированы от первого лица с цитатами/ссылками; чек-лист группы A пройден.

## Фаза 2. Конкурентный анализ (аналитик рынка)

**Артефакт:** `/02_market/competitors.md`.
**Содержание:** банковские продукты для начинающих ИП/самозанятых (Т-Банк, Сбер, Точка, ВТБ и др.), финтех, AI-сервисы, небанковские инструменты; сравнение по болям из Фазы 1; белые пятна рынка.
**DoD:** ≥8 реальных конкурентов с актуальными тарифами/условиями и ссылками; таблица «боль → кто закрывает → как → чего не хватает»; чек-лист группы A пройден.

## Фаза 3. Инсайты и концепция стратегии (стратег)

**Артефакты:** `/03_strategy/insights.md`, `/03_strategy/concept.md`.
**Содержание:** ключевые инсайты из Фаз 1–2; выбор 2–3 приоритетных отраслей (обоснованный данными); роль банка в жизни предпринимателя; ценностное предложение; ключевая идея; AI-компонент; механики удержания.
**DoD:** каждый инсайт опирается на данные Фаз 1–2; выбраны и обоснованы 2–3 отрасли; для AI-компонента объяснено, почему именно AI; чек-листы групп B и C пройдены.

## Фаза 4. Продуктовые предложения (продакт-менеджер)

**Артефакт:** `/04_products/products.md`.
**Содержание:** новые продукты/сервисы/доработки Платежного бизнеса под стратегию; маппинг на существующие продукты (эквайринг, Альфа-Касса, AlfaPay, СБП, «Подели», «Нетмонет», Mozen, «Твои платежи»); приоритизация; ограничения (54-ФЗ, несовершеннолетние).
**DoD:** каждое предложение связано с болью из Фазы 1 и продуктом периметра; юридические ограничения учтены; чек-листы групп C и D пройдены.

## Фаза 5. Продвижение (маркетолог)

**Артефакт:** `/05_gtm/promotion.md`.
**Содержание:** каналы и механики привлечения 17–25 (образовательные программы, блогеры, вузы/колледжи, комьюнити), воронка, CJM привлечения, бюджетная логика.
**DoD:** каналы подтверждены реальными примерами/данными об аудитории; механики не создают репутационных рисков; чек-лист группы D (в части рисков) пройден.

## Фаза 6. Эффект для банка (финансовый аналитик)

**Артефакт:** `/06_impact/impact.md`.
**Содержание:** модель эффекта (воронка привлечения, обороты эквайринга, комиссионный доход, удержание/LTV, стоимость привлечения), сценарии, чувствительность.
**DoD:** все допущения явные и обоснованные источниками или помечены [ТРЕБУЕТ ПРОВЕРКИ]; чек-лист группы D пройден.

## Фаза 7. Сборка и подача (руководитель + дизайнер)

**Артефакты:** `/07_deliverables/presentation.md` (структура и контент презентации), MVP (описание/прототип).
**DoD:** сквозная логика «боль → инсайт → решение → эффект» без разрывов; полный прогон по всем 5 группам критериев жюри; ни одного факта без источника.

## Зависимости

Фаза 1 и Фаза 2 могут идти параллельно → Фаза 3 требует обе → Фазы 4, 5, 6 могут идти параллельно после Фазы 3 → Фаза 7 последняя.
