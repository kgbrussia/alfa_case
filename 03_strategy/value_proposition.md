# Ценностное предложение «Альфа-Разгона»

Роль: продуктовый стратег. Вход: strategy_concept.md, persona.md, jtbd.md, banks_ru.md.

## 1. Value Proposition Canvas по персонам

### Персона «Мастер без вывески» (бьюти, НПД/без регистрации)

| Customer Profile | Value Map |
|---|---|
| **Pains:** страх «налоговая заметит переводы»; «зарегистрируюсь — замучают»; терминал дорог для 40 клиентов/мес; чаевые умирают с наличными; дорогие процедуры не по карману клиенткам | **Pain relievers:** «Штурман» оформляет НПД за вечер и объясняет, что можно/нельзя; прием по **СБП-QR** с 0 ₽ фикса — дешевле и «солиднее» личной карты; комплаенс-предохранитель вместо внезапной блокировки; **«Нетмонет»** — чаевые и отзывы по QR; **«Подели»** на процедуры от 5 тыс. ₽ (клиентки 18+) |
| **Gains:** выглядеть «настоящим бизнесом» перед клиентками; спокойствие; рост до своего кабинета | **Gain creators:** чек после оплаты автоматом (НПД-чек из «Моего налога» через интеграцию); бенчмарк «мастера твоего профиля в городе берут X»; при переезде в кабинет — mPOS/AlfaPOS и запись через партнерские YCLIENTS/Dikidi без смены банка |

### Персона «Селлер» (розница/маркетплейсы, ИП)

| Customer Profile | Value Map |
|---|---|
| **Pains:** кассовые разрывы между выплатами МП и закупкой; налог не отложен; помощники получают «с личной карты»; зависимость от одной платформы; «не вижу прибыли» | **Pain relievers:** прогноз кэшфлоу на связке «график выплат МП + счет»; **налоговая автокопилка** (% с каждого поступления); **массовые выплаты/Mozen** в лайт-режиме на 1–5 исполнителей; микро-оборотка от оборота под закупку (предодобрение по данным); юнит-экономика от «Штурмана» на реальных цифрах счета |
| **Gains:** пережить сезон закупки; выйти из-под власти МП; масштаб | **Gain creators:** «свой канал за вечер»: **интернет-эквайринг/«Твои платежи»** + платежные ссылки + **«Подели»** для конверсии; сравнение своей динамики с нишей; лестница к офлайн-точке без смены банка |

### Персона «Первая точка» (HoReCa, ИП с командой)

| Customer Profile | Value Map |
|---|---|
| **Pains:** собрать счет+кассу+эквайринг+СБП к дате открытия; комиссия съедает маржу на чеках 350–600 ₽; чаевые команде; сезонные разрывы; HoReCa — лидер смертности | **Pain relievers:** пакет **«Первая точка»**: Альфа-Касса + торговый эквайринг + **СБП** (низкая комиссия на мелких чеках) + AlfaPay одним договором к дате открытия; **«Нетмонет»** для команды и QR-оплаты счета; **массовые выплаты** на смены; система раннего предупреждения с бенчмарками района (данные эквайринга 5 трлн ₽) |
| **Gains:** дожить до окупаемости (12–18 мес); вторая точка | **Gain creators:** еженедельный AI-разбор точки против района («трафик по улице упал у всех» vs «только у тебя»); спасательный протокол при красных флагах; при росте — кассы самообслуживания, вторая касса, зарплатный проект |

## 2. Формулировки ценностного предложения

**Главная (14 слов):**
> **«Прими первую оплату уже сегодня — а мы предупредим о проблемах раньше, чем они убьют бизнес».**

**Адаптации по отраслям:**
- **Бьюти:** «Принимай оплату красиво: QR вместо "переведи на карту", чаевые без наличных — и никакого страха перед налоговой».
- **Розница/МП:** «Банк, который видит твой кассовый разрыв за месяц и дает оборотку под твои же продажи».
- **HoReCa:** «Касса, эквайринг и СБП к дате открытия — и второй пилот, который следит, чтобы точка дожила до окупаемости».

## 3. Дифференциация от трех главных конкурентов (по banks_ru.md)

| Конкурент | Их ценностное предложение (фактическое) | Наша дифференциация |
|---|---|---|
| **Т-Банк** | «Все для бизнеса онлайн, лучший контент для новичков» (Бизнес-секреты, бесплатная регистрация, терминал за 0 ₽) | Контент учит — «Разгон» ведет и отвечает: не статья «как не попасть под 115-ФЗ», а предохранитель, который не дал под него попасть. Плюс лестница с 14 лет и дочки («Нетмонет», «Подели»), которых у Т-Банка нет |
| **Точка** | «Банк для селлеров с ИИ-ассистентом» (тариф «Ноль», аналитика МП, ассистент для 500 тыс. продавцов WB) | Точка — про онлайн-торговлю; «Разгон» — про все три отрасли сегмента, включая офлайн (бьюти, HoReCa), где у Точки нет ни торгового эквайринга-масштаба, ни чаевых, ни BNPL. И у Точки нет розничной молодежной базы для захвата на этапе «хочу» |
| **Озон Банк** | «Деньги селлера внутри Ozon: счет в клик, мгновенные выплаты, кредит под обороты» | Озон заперт в своей платформе — «Разгон» строит бизнес, который переживет любую платформу: свой канал продаж, диверсификация, офлайн. Для клиента это разница между «банком одного маркетплейса» и «банком моего дела» |

**Тест на копируемость:** тариф и терминал за 0 ₽ копируются за квартал; система раннего предупреждения на данных 5 трлн ₽ эквайринга + дочерние сервисы + молодежная розничная база + горизонт «растим с 14 лет» — не копируются, потому что требуют активов, а не бюджета (см. market_synthesis §4).
